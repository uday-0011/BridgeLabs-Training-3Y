# Assignment 5 - JavaScript Functions

This folder contains one JavaScript file for each of the 9 assignment questions.

## Files
1. `q1_greet_callback.js` - callbacks and callback flow
2. `q2_apply_operation.js` - callbacks passed as operations
3. `q3_arrow_function_this.js` - arrow function `this` vs normal function `this`
4. `q4_car_prototype.js` - constructor functions and shared prototype methods
5. `q5_person_student_inheritance.js` - constructor-function inheritance
6. `q6_person_faculty_professor_chain.js` - multi-level prototype chain
7. `q7_closure_multiplier.js` - closures
8. `q8_custom_my_map.js` - custom array `myMap()` method
9. `q9_es6_class_inheritance.js` - `class`, `extends`, and `super()`

## How to run
Open a terminal in this folder and run an individual file with Node.js, for example:

```bash
node q1_greet_callback.js
```

Run the other files by replacing the filename. Each file is independent.
