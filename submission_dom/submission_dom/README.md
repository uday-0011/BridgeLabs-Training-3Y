## How to run

These are browser DOM projects, so open each corresponding `.html` file in a browser (or use VS Code Live Server). Keep each HTML, CSS, and JS file together in this folder. The image gallery uses sample images hosted by picsum.photos, so it requires an internet connection for those images.

The JavaScript files use core JavaScript and browser DOM APIs only; no frameworks are used.
