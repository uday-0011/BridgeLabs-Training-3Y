Responsive CSS Cheat Sheet

Four building blocks for layouts that adapt.

Filters

Adjust the appearance of images and other elements with visual effects.

filter: grayscale(100%);

Media Queries

Apply CSS rules only when a viewport matches a chosen condition.

@media (max-width: 700px) { ... }

Responsive Design

Build interfaces that adapt to different screens and user contexts.

width: min(100%, 70rem);

Typography

Scale text fluidly while keeping it within readable limits.

font-size: clamp(1rem, 2vw, 1.5rem);

CSS Grid

Create two-dimensional layouts with flexible rows and columns.

grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));

Flexible Media

Prevent images from overflowing their containing element.

img { max-width: 100%; }
