THE FOUNDATIONS

Three principles of responsive design

Build flexible experiences, not fixed screenshots.

01

Fluid Layouts

Use flexible units and layout systems so content can expand or contract with available space.

.layout {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
}
02

Flexible Media

Make images and videos fit their containers without overflowing or losing their proportions.

img, video {
  max-width: 100%;
  height: auto;
}
03

Breakpoints

Introduce layout changes when the content needs more room or becomes crowded.

@media (max-width: 600px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
Flexible first. Specific when needed.
