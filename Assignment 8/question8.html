Understanding box-sizing

Compare how the CSS box model calculates an element's width.

content-box

Width: 220px
Padding: 24px
Border: 5px

The default value adds padding and border outside the declared width. Total width is 220 + 48 + 10 = 278px.

border-box

Width: 220px
Padding: 24px
Border: 5px

With border-box, padding and border are included inside the declared width. Total width stays 220px.
