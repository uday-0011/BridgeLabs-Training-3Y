# JS ES Feature — Assignment 3

This folder contains one standalone JavaScript file for each of the 10 assignment questions.

## Files
- `q1_dynamic_data_parser.js`
- `q2_employee_bonus_calculator.js`
- `q3_transaction_validator.js`
- `q4_debugging_mystery.js`
- `q5_hoisting_lab.js`
- `q6_pyramid_pattern.js`
- `q7_smart_calculator.js`
- `q8_strict_mode_showdown.js`
- `q9_json_audit.js`
- `q10_nested_hoisting_closures.js`

## Run
Install Node.js, open a terminal in this folder, then run a file like:

```bash
node q1_dynamic_data_parser.js
```

For Q6, the program asks for a height; press Enter to use the default height of 5.

## Notes
- Each file is independent and uses `"use strict"` where applicable.
- Q4 includes the broken line as a comment and then a corrected version so the file can run.
- Q5 explains the original hoisting sequence and runs a fixed version.
- Q8 demonstrates strict-mode syntax failure safely using `Function`, since putting a duplicate-parameter function directly in a strict file would prevent the whole file from running.
- Debugger steps are included as comments in the relevant files.
