# Submission of JS Classes — Assignment 4

Contains solutions for all 9 questions. Browser-based questions include both HTML and JavaScript files; console-based questions use standalone `.js` files.

## Run browser questions
Open the matching HTML file in a browser, or use VS Code Live Server if available:
- Q1: `q1_ecommerce_product_manager.html`
- Q2: `q2_student_form_validator.html`
- Q4: `q4_custom_form_builder.html`
- Q5: `q5_movie_ticket_booking.html`
- Q7: `q7_login_form_validation.html`
- Q8: `q8_dynamic_object_updater.html`

Each HTML file loads its corresponding JavaScript file.

## Run console questions
Install Node.js, open a terminal in this folder, then run:
```bash
node q3_library_management_system.js
node q6_employee_management_system.js
node q9_shopping_cart_total.js
```

All files use core JavaScript and include comments. Q2 and Q5 use DOM forms because their requirements include visible input borders/messages and ticket display.
