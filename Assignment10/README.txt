How to run:
1. Extract the Assignment10 folder.
2. Keep each HTML file beside its matching CSS file.
3. Open the HTML file in a browser with internet access.
4. Bootstrap 5 is loaded using its CDN. Images are also loaded from Unsplash.
5. Bootstrap JavaScript is included only on pages needing interactive Bootstrap components: the responsive navbar, dismissible alert, and carousel.

Note: Some sample links and form buttons are visual demonstrations and do not connect to a live backend.
